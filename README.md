# Fanshawe Fashion Design Website - The Grad Collective 2026

---

## ✨ Project Introduction 
The **Fanshawe Fashion Design Website** is a responsive, mobile-first platform that showcases the achievements of Fanshawe Fashion Design students. The site highlights event details, individual student portfolios, and program information, while promoting the Fashion Design program through interactive visuals and media.  

This is a **team-based project** with four members. We earned this opportunity after being runners-up for the website we created for the Interactive Media Design program.

---

## 🎯 Project Objectives 
- Develop a **mobile-first, responsive website** using semantic HTML and CSS Grid.  
- Provide **event details** including purpose, date, time, and location.  
- Introduce and promote the **Fashion Design diploma program**.  
- Integrate a **custom video player** showcasing the program and event.  
- Implement a **mobile hamburger menu** with smooth open/close animation.  
- Maintain a **professional GitHub workflow** with proper branching, README documentation, and best practices.

---

## 🔧 Technologies Used 
- **HTML** – Proper document outline, semantic tags 
- **CSS** – Grid layout, responsive design, transitions & animations 
- **JavaScript** – Custom video controls 
- **GitHub** – Repo setup, branching/merging, README documentation, workflow best practices 
- **Figma** – Wireframing, and collaborative UI/UX design 
- **Adobe Suites (Illustrator, After Effects, Premiere Pro)** – Branding assets, SVG logos, video editing 
- **Trello** – Task assignment, sprint planning, and project management 

---

## 🌟 Key Features 
- **Mobile Hamburger Menu** – Animated navigation menu designed for mobile versions with smooth open/close transitions. 
- **Invitation Section** – Event invitation with clear date, time, and location details. 
- **Fashion Design Program Showcase** – A section introducing the Fashion Design diploma, featuring visuals and text about the program with a direct link to the official Fanshawe Fashion Design page. 
- **Footer with Branding & Navigation** – Contains Fanshawe branding, address, quick links, event buttons, social media icons, and project credits (Team High Five, 2026).

## 🔀 GitHub Workflow 

**Branches Naming Convention:** 
- `main` – stable branch 
- `dev.[name].html` – web development 
- `dev.[name].js` – JavaScript 
- `des.[name].css` – Styling, animations 

**Practices Followed:** 
- Descriptive commit messages 
- Pull requests & review before merging to main
